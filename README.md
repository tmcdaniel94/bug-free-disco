# E-commerce Back End Starter Code

## Description
This app is designed to perform as the back-end of an E-commerce website. Users can manage their products, product categories, and product tags by running the server through Insomnia, and edit, update, view, or delete their data. The app is navigated using routes and CRUD criteria. 

## Credits
Created using starter code from UT's Full Stack Web Development continued education program.

## Installation
Clone code into git and get started by entering 'npm install' in the terminal. Enter 'npm run start' to start server, then open routes in Insomnia. Users can GET, PUT, POST, and DELETE information as they please.
